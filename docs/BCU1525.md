# BCU-1525 board facts for Stage 3 (xcvu9p-fsgd2104-2L-e)

## Source

The BCU-1525 shares the VCU1525 / Alveo U200 pinout.
- **Primary source:** Corundum's `fpga/mqnic/Alveo/fpga_100g/fpga_au200.xdc` (BSD-2-Clause, github.com/corundum/corundum, fetched 2026-10-21). Corundum's own VCU1525 build (`fpga_VCU1525/Makefile`) uses that XDC.
- **Cross-check:** the cage-0 pins and control pins recorded in `claude_project/aurora_uart_test` (FS0 AT20, FS1 AU22, ResetL BE17, LPMode BD18, ModPrsL BE20, IntL BE21) are identical to Corundum's QSFP0.
- **The lab notes have the quad names wrong.** They call the cage on pins K..N "Quad X1Y11". By Corundum's site comments those pins are quad 231 = X1Y12. This matches the "cage labels swapped" gotcha in those notes.

## QSFP cages (GTY)

| | QSFP0 | QSFP1 |
|---|---|---|
| GTY quad | 231 = GTYE4_COMMON_X1Y12 | 230 = GTYE4_COMMON_X1Y11 |
| channels | X1Y48..X1Y51 | X1Y44..X1Y47 |
| lane 0 RX / TX | N4/N3 / N9/N8 | U4/U3 / U9/U8 |
| lane 1 RX / TX | M2/M1 / M7/M6 | T2/T1 / T7/T6 |
| lane 2 RX / TX | L4/L3 / L9/L8 | R4/R3 / R9/R8 |
| lane 3 RX / TX | K2/K1 / K7/K6 | P2/P1 / P7/P6 |
| MGTREFCLK1 (Si5335) | K11/K10 (U9) | P11/P10 (U12) |
| MGTREFCLK0 (SI570 via U43) | M11/M10 | T11/T10 |
| FS[1:0] (10 = 161.1328125 MHz, 01 = 156.25) | AT20, AU22 | AR22, AU20 |
| refclk_reset (drive 0) | AT22 | AR21 |
| ModSelL / ResetL / LPMode | BE16 / BE17 / BD18 | AY20 / BC18 / AV22 |
| ModPrsL / IntL (inputs, pull-up) | BE20 / BE21 | BC19 / AV21 |

- All control pins are LVCMOS12.
- **3-lane build (d = 5, DW = 192):** cores `aurora3_a` / `aurora3_b` (`s3_gen_aurora.tcl l3`) bond lanes 0..2 of each cage (X1Y48..X1Y50, X1Y44..X1Y46) on the same MGTREFCLK1. `s3_bcu1525.xdc` pins lane 0, `s3_bcu1525_l3.xdc` lanes 1 and 2. Port bit i of `qsfp*_rx_p` etc. is cage lane i (the IP's `rxp[i]`, GT channel X1Y48+i / X1Y44+i). The core makes lane 1 the channel-bonding master. A straight DAC joins lane i of one cage to lane i of the other.
- The two cages' MGTREFCLK1 come from two different Si5335 outputs (U9 and U12). Two cores, one per cage, are therefore plesiochronous unless one refclk is shared across quads.

## Other pins

- **300 MHz LVDS system clocks** (SI53340): AY37/AY38, AW20/AW19, F32/E32, J16/H16.
- **LEDs:** BC21, BB21, BA20 (LVCMOS12).
- **USB UART** (FT4232H): BB20 / BF18.
- **I2C:** SCL BF20, SDA BF17.

## JTAG on build-host

| Cable serial | Card | hw_server target |
|---|---|---|
| `PCIE-BCU-JTAG` (FT4232H, `/dev/serial/by-id/usb-Xilinx_CB-U1-AEBE_PCIE-BCU-JTAG-*`) | PCIe card at 0000:82:00.0, shared with fable5_llm under `.fable5_board.lock` | `localhost:3121/xilinx_tcf/Xilinx/PCIE-BCU-JTAG` |
| (to be recorded on first enumeration) | desk card | — |

- **Hazard with a second cable:** `fable5_llm/synth/scripts/program.tcl` opens the first hw_server target (a bare `open_hw_target`). Once the desk card enumerates, that flow can open the wrong card.
- **Our flow** names its target explicitly and refuses `PCIE-BCU-JTAG`.
